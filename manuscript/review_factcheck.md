## Items checked, no problem found

- `hierarchical_bootstrap`, `paired_bootstrap`, `is_win`: logically correct. `minimum_detectable_effect` uses (1.96+0.84)·sqrt(d/n), which is a standard McNemar approximation. It uses n=200 although penguins has n=96 (MDE is about 7.3 points there); this is worth a footnote.
- `acceptance_rules`: selection is argmax of validation score with ties to the first candidate, which approximates the loop for strict but only approximates "ties accepted" (an online non-strict loop would keep replacing the incumbent). The large-gate delta is measured on half the test split, and the Table 8 caption says so.
- D1 rule thresholds, `main_grid` verdict (the `2*n_cells/45` scaling is exact for 45 cells), and the win criterion are applied as written.
- I could not verify that the D1-D3 text in the committed protocol (8fd1397) is unchanged by later commits, because no git commands were allowed; the file now contains the later amendments.

## Verdict

The headline null for the *specified* MPIR procedure with the 1.7B model is real and reproduces from the raw logs: 1 of 80 runs changed, 0 of 45 cells won, and the one accepted candidate lowered test accuracy. The headline numbers are correctly transcribed.

Four things need fixing before submission.

1. **The mechanistic explanations lean on a harness asymmetry (F1).** V1/V2 candidates are not given an answer-format line while V3 candidates are, and about 92% of the 1.7B validated candidates score 0 solely because the tags are missing. That undermines "candidates are much worse", the 0.92 correlation, and the rubric-versus-free-rewrite comparison.
2. **The "14-point" cost of the uncorrected loop is over-generalised (F2).** It is a 1.7B re-enactment that deviates from protocol G6; the literal G6 reading gives 29, two cells drive it, and the Conclusion's statement about the first evaluation is unsupported.
3. **The "format repair" account of the strong-refiner gains is wrong for 2 of the 4 wins (F3).** The 235B hyperbaton/PromptWizard win (+30) and Luna's only win (+27) are in a cell whose baseline had a correct format. This weakens the Abstract and Conclusion sentence about "coincide with a repaired answer format".
4. **Protocol disclosure is incomplete (F5, F6).** D2 "met" for 235B is post hoc; the "all amendments before results were inspected" sentence is false for the 2026-10-21 amendment; 4B/8B refiners are still listed as used; the seed count and the pooling rule are not disclosed.

The V3 paragraph (F4) misstates the gate's protective role. Everything else is MEDIUM or LOW.

Recommended status: major revision of the text of 5.4-5.6, 5.9, the Abstract and the Conclusion; no new experiments needed apart from the cheap offline re-scoring in F1.
