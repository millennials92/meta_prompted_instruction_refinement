# Archive

Earlier manuscripts, submission packages, and development records are preserved here.
Current publication files are in [submission_final](../submission_final/).

- manuscripts/submission_revision/: first revision and upload package.
- manuscripts/submission_revision2/: second revision and original supplementary archive.
- manuscripts/pre_sync_final/: final-file package before the abstract and DOI update.
- manuscripts/elsevier/: earlier Elsevier manuscript.
- development/: rebuild notes, revision logs, reviews, and historical manuscript utilities.

Historical titles, status statements, and correspondence describe their original versions.
Original repository-relative paths are preserved within each archive group where possible.
The archived utilities are records of earlier workflows, not the current build entry points.
